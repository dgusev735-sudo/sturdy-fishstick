# 💰 Деньги под контролем — Telegram-бот учёта финансов

Личный трекер расходов и доходов прямо в Telegram. Записывай траты по категориям,
смотри отчёты и графики, устанавливай бюджеты, экспортируй данные в CSV.

## Возможности

- ➕ **Добавление расходов и доходов** — через меню кнопок или быстрым вводом текста
- 📊 **Отчёты** — за сегодня, неделю, месяц, год. Сводка по категориям
- 📈 **Графики** — круговая диаграмма по категориям, линейный тренд за 30 дней, статус бюджетов
- 💰 **Бюджеты** — устанавливай лимиты по категориям, получай уведомления при превышении
- 📁 **Экспорт** — выгрузка всех операций в CSV (открывается в Excel/Google Sheets)
- 🗂 **Категории** — добавляй и удаляй свои категории расходов/доходов
- 🕘 **История** — последние 10 операций с возможностью удаления по id

## Быстрый старт

### 1. Установить Python 3.10+

Скачать с [python.org](https://www.python.org/downloads/). При установке на Windows отметить галочку **«Add Python to PATH»**.

### 2. Создать бота через @BotFather

1. Открой Telegram, найди `@BotFather`
2. Отправь команду `/newbot`
3. Введи имя бота (например, «Мои Деньги»)
4. Введи username (например, `my_money_tracker_bot` — должно заканчиваться на `_bot`)
5. Скопируй **токен** вида `123456789:AAExample...`

### 3. Установить зависимости

```bash
cd telegram_finance_bot
pip install -r requirements.txt
```

### 4. Настроить токен

Скопируй `.env.example` в `.env` и вставь свой токен:

```bash
cp .env.example .env
```

Открой `.env` в любом редакторе и замени значение `BOT_TOKEN` на свой.

### 5. Запустить бота

```bash
python bot.py
```

В терминале должно появиться: `Бот запущен. Нажмите Ctrl+C для остановки.`

### 6. Открыть бота в Telegram

Найди бота по username, который задал в @BotFather, нажми **Start** и следуй инструкциям.

## Как пользоваться

### Быстрый ввод (без меню)

Просто отправь сообщение боту — он распознает формат:

| Что отправить                | Что произойдёт                              |
| ---------------------------- | ------------------------------------------- |
| `1500`                       | Добавит расход 1500 ₽, спросит категорию    |
| `1500 продукты`              | Расход 1500 ₽ в категорию «Продукты»        |
| `1500 продукты хлеб`          | Расход с заметкой «хлеб»                    |
| `+50000 зарплата`            | Доход 50000 ₽ в категорию «Зарплата»        |
| `доход 30000 фриланс проект` | Доход 30000 ₽ с заметкой «проект»           |
| `расход 800 транспорт метро` | Расход 800 ₽ в «Транспорт», заметка «метро» |

### Команды

- `/start` — приветствие и меню
- `/help` — список всех команд
- `/cancel` — отменить текущее действие
- `/report` — открыть меню отчётов
- `/chart` — открыть меню графиков
- `/budget` — открыть меню бюджетов
- `/export` — экспорт в CSV
- `/last` — последние 10 операций
- `/delete 5` — удалить операцию #5 (id виден в «Последние»)

### Главное меню (кнопки внизу)

| Кнопка          | Действие                                      |
| --------------- | --------------------------------------------- |
| ➕ Расход        | Добавить расход по шагам                      |
| ➕ Доход         | Добавить доход по шагам                       |
| 📊 Отчёт         | Сводка по периодам                            |
| 📈 График        | Круговые и линейные графики                   |
| 💰 Бюджеты        | Установить и просмотреть лимиты                |
| 📁 Экспорт       | Выгрузка всех операций в CSV                  |
| 🗂 Категории       | Добавить / удалить / показать категории       |
| 🕘 Последние      | Последние 10 операций                         |
| ❓ Помощь         | Список команд                                 |

## Хранение данных

Все данные хранятся локально в файле `finance.db` (SQLite). Это значит:

- ✅ Работает без интернета (кроме доступа к Telegram)
- ✅ Никто, кроме вас, не имеет доступа к данным
- ✅ Легко бэкапить — просто скопируйте `finance.db`
- ❌ Не синхронизируется между устройствами (один процесс бота = одна база)

### Бэкап

```bash
cp finance.db finance_$(date +%Y%m%d).db
```

## Запуск как сервис (опционально)

### На Linux через systemd

Создай файл `/etc/systemd/system/finance-bot.service`:

```ini
[Unit]
Description=Telegram Finance Bot
After=network.target

[Service]
User=YOUR_USERNAME
WorkingDirectory=/path/to/telegram_finance_bot
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Активируй:

```bash
sudo systemctl daemon-reload
sudo systemctl enable finance-bot
sudo systemctl start finance-bot
sudo systemctl status finance-bot
```

### На Windows через планировщик

1. Создай `.bat`-файл `run_bot.bat`:
   ```bat
   @echo off
   cd /d C:\path\to\telegram_finance_bot
   python bot.py
   ```
2. Открой «Планировщик заданий» → «Создать простую задачу»
3. Триггер: при входе в систему
4. Действие: запустить `run_bot.bat`

## Устранение проблем

**`BOT_TOKEN не задан!`** — создай `.env` рядом с `bot.py` и вставь токен.

**`ModuleNotFoundError: No module named 'telegram'`** — выполни `pip install -r requirements.txt`.

**Бот не отвечает** — проверь, что токен правильный и не используется другим процессом.
Один токен = один одновременно работающий бот.

**Кириллица в графиках отображается квадратиками** — это на сервере без шрифта Noto Sans.
Установи: `sudo apt install fonts-noto-cjk` (на Debian/Ubuntu).

**Конфликт Conflict after X seconds (terminated by other getUpdates request)** —
бот уже запущен в другом месте. Останови другой процесс и попробуй снова.

## Безопасность

- Токен бота **никогда не публикуй** в открытых репозиториях (добавь `.env` в `.gitignore`)
- База `finance.db` содержит твои личные финансы — не коммить её в публичные репозитории
- Каждый пользователь Telegram видит только свои данные (привязка по `user_id`)
