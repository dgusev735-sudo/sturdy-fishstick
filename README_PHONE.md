# 📱 Инструкция для запуска с телефона (без компьютера)

Эта инструкция — для случая, когда у тебя **только Android-телефон**, и ты хочешь, чтобы бот работал **24 часа в сутки, 7 дней в неделю**, бесплатно.

Мы будем использовать **бесплатный облак Koyeb** — это сервис, на котором можно запустить бота. Бот будет работать в интернете, и тебе не нужно держать телефон включённым.

---

## 📋 Что тебе понадобится

1. **Телефон на Android** (у тебя уже есть)
2. **Токен бота** (получишь в Шаге 1)
3. **GitHub-аккаунт** (заведёшь бесплатно в Шаге 2)
4. **Koyeb-аккаунт** (заведёшь бесплатно в Шаге 3)

Всё бесплатно. Никакой банковской карты не нужно.

---

## Шаг 1. Создать бота в Telegram и получить токен

1. Открой Telegram на телефоне
2. В поиске введи `@BotFather` — выбери бота с **синей галочкой**
3. Нажми **«Запустить»** / **Start**
4. Отправь ему команду:
   ```
   /newbot
   ```
5. BotFather спросит имя — напиши, например:
   ```
   Мои деньги
   ```
6. BotFather спросит username (должен заканчиваться на `bot`) — придумай уникальный, например:
   ```
   my_money_alex_2024_bot
   ```
   (если занято — попробуй другой, добавь цифры)
7. BotFather пришлёт длинное сообщение. В нём будет **токен** — длинная строка вида:
   ```
   7894561234:AAH8fKdL3vBx9NqW_pYzRtUvXmNbCdEfGhI
   ```
8. **Скопируй этот токен** (долгим нажатием → «Копировать»). Сохрани его в заметки, чтобы не потерять.

## Шаг 2. Загрузить код бота на GitHub

GitHub — это сайт, где хранят код. У нас будет бесплатный частный репозиторий с кодом бота.

### 2.1. Зарегистрироваться на GitHub

1. Открой в браузере телефона: **[github.com](https://github.com)**
2. Нажми **Sign up** (вверху справа)
3. Введи email, придумай пароль и username (английскими буквами, например `alexmoney`)
4. Подтверди email (зайди на почту, открой письмо от GitHub, нажми ссылку)
5. На вопрос «What do you want to do?» выбери что угодно, нажми Continue
6. На вопрос про платный план — выбери **Free** (бесплатный)

### 2.2. Создать новый репозиторий

1. Войди в GitHub (если ещё не вошёл)
2. Вверху справа нажми на свой аватар → **Your repositories**
3. Нажми зелёную кнопку **New**
4. В поле **Repository name** напиши:
   ```
   telegram-finance-bot
   ```
5. Под названием выбери **Private** (чтобы никто не видел код)
6. ❗️ **Важно:** прокрути вниз и поставь галочку **«Add a README file»** (нужно, чтобы репозиторий не был пустым)
7. Нажми зелёную кнопку **Create repository**

### 2.3. Загрузить файлы проекта

Сейчас в репозитории только файл `README.md`. Нам нужно добавить ещё 5 файлов:
- `bot.py`
- `db.py`
- `charts.py`
- `config.py`
- `requirements.txt`
- `Dockerfile`

**Как загрузить файлы с телефона:**

1. Скачай ZIP-архив с кодом бота (я тебе дам ссылку)
2. Распакуй ZIP — внутри будет папка `telegram_finance_bot` с 8-9 файлами
3. Теперь для каждого файла из списка выше:
   - Открой файл в любом текстовом редакторе на телефоне (например, «Файлы» → открой файл → «Поделиться» → скопируй содержимое)
   - ИЛИ просто запомни где он лежит
4. Зайди в GitHub → открой свой репозиторий `telegram-finance-bot`
5. Нажми кнопку **Add file** → **Upload files**
6. Нажми **choose your files** — откроется выбор файлов на телефоне
7. Выбери все 6 файлов (bot.py, db.py, charts.py, config.py, requirements.txt, Dockerfile)
8. Внизу нажми зелёную кнопку **Commit changes**
9. Файлы загрузятся в репозиторий

> ⚠️ **Важно:** файлы `.env.example`, `.gitignore`, `.dockerignore`, `koyeb.yaml` и `README.md` загружать не обязательно. Они не помешают, но и без них работает.

### 2.4. Сделать репозиторий доступным для Koyeb

1. Открой свой репозиторий в GitHub
2. Вверху нажми **Settings** (настройки, последний таб)
3. Прокрути в самый низ до секции **Danger Zone**
4. Нажми **Change visibility**
5. Выбери **Change to public** (публичный)
6. Подтверди, нажав **I want to make this repository public**

> ⚠️ **Почему публичный?** Koyeb на бесплатном тарифе работает только с публичными репозиториями. Токен бота в коде нет — он задаётся отдельно в Koyeb. Так что твой репозиторий безопасен.

## Шаг 3. Запустить бота на Koyeb

### 3.1. Зарегистрироваться на Koyeb

1. Открой в браузере: **[koyeb.com](https://koyeb.com)**
2. Нажми **Sign Up** (вверху справа)
3. Нажми **Sign in with GitHub** (войдёшь через тот же GitHub-аккаунт, что создал в Шаге 2)
4. Разреши Koyeb доступ к твоему GitHub
5. Подтверди email (если попросит)

### 3.2. Создать сервис

1. После входа откроется панель управления Koyeb
2. Нажми синюю кнопку **Create Service** (или **Deploy Service**)
3. Выбери **GitHub** как источник
4. Выбери свой репозиторий `telegram-finance-bot`
5. Выбери ветку `main`
6. В поле **Builder** выбери **Dockerfile** (Koyeb автоматически найдёт твой Dockerfile)
7. В поле **Service type** выбери **Background worker** (это важно! Бот — не веб-сайт, а фоновая программа)
8. В поле **Region** выбери ближайший (Frankfurt, если в Европе)
9. Прокрути вниз до секции **Environment Variables** (переменные окружения)
10. Нажми **Add variable**
11. В поле **Variable name** введи:
    ```
    BOT_TOKEN
    ```
12. В поле **Variable value** вставь свой токен бота (из Шага 1)
13. ❗️ **Очень важно:** рядом с переменной включи переключатель **Secret** (чтобы токен был скрыт)
14. В поле **Instance type** выбери **Free** (бесплатный)
15. Нажми синюю кнопку **Deploy** (или Create)

### 3.3. Подключить постоянное хранилище (чтобы не терять данные)

> ⚠️ Без этого шага твоя база данных будет теряться каждый раз при перезапуске бота.

1. В панели Koyeb открой свой сервис (нажми на него)
2. Перейди на вкладку **Settings** (или Configuration)
3. Найди секцию **Persistent Storage** / **Volumes**
4. Нажми **Add Volume**
5. В поле **Mount path** введи:
   ```
   /data
   ```
6. В поле **Size** выбери минимальное (обычно 1 ГБ)
7. Сохрани настройки
8. Перезапусти сервис (кнопка **Restart** или **Redeploy**)

> ⚠️ Если у Koyeb не будет бесплатного Volume — ничего страшного. Бот всё равно будет работать, но данные будут теряться при перезапуске. Тогда используй Вариант с Termux (ниже) или платный Volume за ~$2/мес.

### 3.4. Проверить, что бот работает

1. В панели Koyeb открой свой сервис
2. Перейди на вкладку **Logs** (логи)
3. Должно появиться сообщение:
   ```
   Бот запущен. Нажмите Ctrl+C для остановки.
   ```
4. Если есть ошибки — бот их покажет тут же

5. Открой Telegram, найди своего бота по username (например `my_money_alex_2024_bot`)
6. Нажми **Запустить** / **Start**
7. Бот должен прислать приветственное сообщение

**Готово!** Бот работает 24/7, даже когда телефон выключен. Доступ к нему — через Telegram.

## 🆘 Если что-то не работает

### Бот не отвечает в Telegram
1. Открой Koyeb → сервис → вкладка **Logs**
2. Посмотри последние строки. Если есть ошибка — пришли мне текст ошибки
3. Частая причина — неправильно введённый токен. Проверь в Koyeb → Settings → Environment Variables, что `BOT_TOKEN` заполнен правильно

### «Conflict. terminated by other getUpdates request»
Это значит, что бот уже где-то запущен (например, ты раньше запустил его на компьютере). Останови все копии, оставь только одну на Koyeb.

### Данные исчезают после перезапуска
Ты пропустил Шаг 3.3 — не подключил постоянное хранилище Volume. Вернись к нему.

### Koyeb говорит «free tier limit reached»
Бесплатный тариф Koyeb даёт один сервис. Если ты уже что-то там запускал — удали старый сервис, оставь только бота.

## 🔄 Запасной вариант: Termux (без облака)

Если с Koyeb не получится — есть альтернатива. Бот будет работать только когда у тебя открыт Termux на телефоне.

1. Установи приложение **Termux** (только из [F-Droid](https://f-droid.org/packages/com.termux/) — версия из Google Play устаревшая и не работает)
2. Открой Termux, введи:
   ```
   pkg update && pkg install python git
   ```
3. Установи зависимости:
   ```
   pip install python-telegram-bot matplotlib python-dotenv
   ```
4. Скачай ZIP с кодом бота, распакуй в память телефона
5. Перейди в папку:
   ```
   cd storage/downloads/telegram_finance_bot
   ```
   (путь может отличаться — нужно разрешить Termux доступ к файлам через `termux-setup-storage`)
6. Создай файл `.env`:
   ```
   echo "BOT_TOKEN=твой_токен_здесь" > .env
   ```
7. Запусти бота:
   ```
   python bot.py
   ```

Бот будет работать, пока открыт Termux. Если закрыть — бот остановится.

## ❓ Частые вопросы

**Это правда бесплатно?**
Да. GitHub и Koyeb имеют бесплатные тарифы, которых хватает для одного бота. Ничего платить не нужно.

**Токен бот у меня украдут?**
Нет, если ты:
- Сделал репозиторий публичным, но **токен ввёл в Koyeb как Secret** (Шаг 3.3)
- Не написал токен в коде bot.py, не закоммитил `.env` в GitHub

**Можно ли использовать бота с нескольких Telegram-аккаунтов?**
Да. Каждый пользователь видит только свои данные (по `user_id`). Можешь поделиться ботом с друзьями.

**Что если Koyeb закроет бесплатный тариф?**
Тогда можно перейти на Render, Fly.io, PythonAnywhere или запустить на своём Android через Termux (запасной вариант выше).
